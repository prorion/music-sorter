# music-sorter

mp3 음악 자동 장르·분위기 분류 및 재생목록 생성기

대량의 mp3 파일을 **장르 / 분위기 / 컨셉**으로 자동 분류하고,
태그별 재생목록(m3u)을 만들어 PC와 폰의 일반 음악 앱에서 바로 들을 수 있게 합니다.

> 현재 설계 단계입니다.
